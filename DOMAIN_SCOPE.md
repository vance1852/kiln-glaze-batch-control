# Kiln Glaze Batch Control

This backend models a deliberately niche traditional craft: coordinating high-temperature ancient-glass kiln firings and glaze batches. Device and rollout entities represent kiln controllers, approved firing recipes, staged configuration changes, temperature/health reports, quality alerts, and audited operator handoffs. The operational workflow is real production coordination, not commerce or a dashboard demo. `SPEC_FREEZE.md` is authoritative for the frozen boundary and reserved runtime capacity.
